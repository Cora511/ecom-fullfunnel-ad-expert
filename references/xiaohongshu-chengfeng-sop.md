# 小红书乘风投放 SOP（笔记种草 + 商品推广 + 直播 + 搜索广告）

## 一、平台特性与投放前提

- 用户决策周期更长，优先看 **7 日支付 ROI**，不看单日 ROI 下结论。
- 素材偏原生种草，**硬广素材很难跑量**，硬广内容甚至会被判定违规限流。
- 搜索广告长尾词价值高，是乘风的效率核心。
- 笔记种草前置积累品类词搜索资产，千川承接搜索流量做收割。

## 二、可用的投放类型

| 类型 | 适用场景 |
|---|---|
| 笔记种草加热 | 新品冷启动、内容蓄水、涨粉 |
| 商品推广 | 直接推商品，转化导向 |
| 搜索广告 | 承接搜索需求，长尾词高效 |
| 直播投放 | 直播间付费加热，注重种草氛围 |

## 三、账户结构搭建规范

```
账户
└── 计划（按投放目标分组：种草 / 转化 / 搜索）
    └── 单元（按人群定向分组）
        └── 笔记素材（A/B 测试）
```

- 种草计划与转化计划分开建，避免目标互相干扰。
- 单次新建计划数量控制在 5 条以内，观察后再扩。
- 搜索计划单独建，与信息流计划分开看数据。

## 四、定向策略

| 阶段 | 定向方式 |
|---|---|
| 前期 | **智能定向**测人群，让系统先找人 |
| 中期 | 叠加**对标达人人群**（同品类/同调性达人粉丝） |
| 后期 | 叠加店铺人群、成交人群、互动人群做复购与二次种草 |

原则：前期不要过早收窄定向，小红书人群标签建立需要样本量。

## 五、笔记内容要求（投放前提）

- 必须是原生种草内容：第一人称、真实体验、有场景。
- 禁止硬广腔：「赶紧买」「全网最低」「限时秒杀」类话术会被限流。
- 图片必须有真实场景实拍，纯白底产品图不适合小红书。
- 埋词自然：标题 1 个核心品类词，首段 1 个人群长尾词，正文小标题埋场景词。

## 六、关键词与搜索广告

- 优先布局**长尾搜索词**（人群词、场景词、问题词、对比词）。
- 搜索广告选词：优先问题词与对比词，转化意图明确。
- 词库搭建方法见 `keyword-mining.md`。
- 搜索计划出价按词分层：高转化词单独建组守排名，长尾词打包放量。

## 七、7 日 ROI 优化逻辑

- 优化周期以 7 天为单位评估，不在第 1~2 天因 ROI 低关停。
- 观察顺序：曝光 → 点击 → 互动（收藏/评论）→ 进店 → 支付。
- 曝光低 → 内容问题或出价问题；点击低 → 封面/标题问题；互动低 → 内容不种草；支付低 → 承接链路问题。

## 八、直播投放要点

- 注重直播间种草氛围，不要做成纯叫卖场。
- 关注指标：观看人数、平均停留、商品点击、7 日支付 ROI。
- 直播素材同样要避免硬广判定。

## 九、7 天调优规则

| 时间 | 动作 |
|---|---|
| 第 1 天 | 智能定向 + 3~5 条原生笔记，测试曝光与点击 |
| 第 2 天 | 不动出价，观察互动率（收藏/评论），关停曝光极低的笔记 |
| 第 3 天 | 保留互动好的笔记，追加预算；新增 2~3 条长尾词搜索计划 |
| 第 4 天 | 叠加对标达人人群测试 |
| 第 5 天 | 把搜索计划中有点击的词提为独立组，单独控出价 |
| 第 6 天 | 对 7 日 ROI 达标的计划加预算，未达标但互动好的继续观察 |
| 第 7 天 | 复盘：哪些笔记带来搜索资产沉淀，制定下周埋词与素材计划 |

## 十、与千川的协同

- 小红书负责蓄水：积累品类词/品牌词搜索资产，沉淀意向人群。
- 千川负责收割：承接小红书种草回流搜索流量、商城搜索人群。
- 人群回流：千川成交人群包反向推送小红书做二次种草复购（见 `fullfunnel-strategy.md`）。

## 十一、输出纪律

所有数值（预算、出价、ROI 目标）标注为预估；小红书不承诺短期 ROI，需给足 7 日观察窗口。
