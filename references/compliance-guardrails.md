# 合规红线与违禁词处理

> 本文件为硬性约束。任何素材产出、话术输出前必须过一遍本清单。

## 一、绝对禁用（出现即违规，必须替换）

### 1. 极限词 / 绝对化用语

最、最好、最佳、最强、最优、第一、NO.1、顶级、极致、唯一、独家、绝无仅有、史无前例、空前绝后、世界领先、国内首创、全网最低、史上最低、绝对、100%、永久、彻底、根治、完全、零风险、无效退款（无依据时）

### 2. 虚假功效宣称

- 美妆：美白、祛斑、祛痘、抗炎、修复受损（医疗化表述）、换肤
- 食品/保健：治疗、治愈、疗效、防癌、抗癌、降血压、降血糖、增强免疫力、改善睡眠（作为功效宣称时）
- 家电/3C：杀菌率 99.99%（无检测依据）、医用级、零辐射
- 通用：包治、秒见效、当天见效、三天见效

### 3. 违规身材焦虑话术

- 「胖的人不配穿」「不瘦没人爱」「瘦下来才有资格」
- 任何以羞辱身材、制造外貌焦虑推动购买的表达

### 4. 医疗 / 医疗器械类

不得宣称治疗效果、不得与药品对比、不得暗示替代治疗。

## 二、合规替代写法对照

| 违规写法 | 合规替代 |
|---|---|
| 全网最低价 | 近期到手价 XXX（标注活动期限） |
| 效果最好 | 我用下来觉得比较适合我的情况 |
| 100% 有效 | 个人使用感受，效果因人而异 |
| 立刻见效 | 坚持用了一段时间后的感受 |
| 绝对安全 | 成分表里没有 XX，敏感肌建议先做局部测试 |
| 顶级材质 | 材质为 XXX（给出具体材质名） |
| 永久保持 | 正常使用情况下可以维持 |
| 治好了我的 XX | 我的 XX 情况在用之后有改善（不承诺效果） |

## 三、分平台合规要点

### 抖音 / 千川

- 直播间画面合规：无绝对化用语、商品与讲解一致、无违规引导
- 短视频不得出现虚假对比、伪造检测报告
- 直播话术中「最」字高频出现是常见驳回原因

### 小红书

- 硬广话术会被判定违规限流：「赶紧买」「限时秒杀」「全网最低」
- 不得伪造使用前后对比（尤其是身材、皮肤对比）
- 医疗健康类内容需谨慎，不得做功效承诺

## 四、输出前必查清单

- [ ] 全文检索极限词，已全部替换
- [ ] 无功效承诺、无疗效暗示
- [ ] 无伪造数据、无伪造检测报告
- [ ] 无身材焦虑、外貌羞辱话术
- [ ] 价格表述已标注活动期限
- [ ] 效果类表述已加「因人而异 / 个人感受」限定
- [ ] 美妆/食品/保健/家电类目已按对应类目规则复核
- [ ] 复刻素材未搬运原文案与画面

## 五、版权与素材使用约束

- 爆款复刻只提取结构框架，禁止搬运原视频文案、画面、BGM 原声。
- 不得使用未授权的达人肖像、品牌 logo。
- 使用第三方素材需确认授权范围。
