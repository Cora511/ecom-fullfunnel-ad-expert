# 子模块 1：素材创作模块

> 触发：上传产品图片 / 提供产品资料，需一次性生成抖音 + 小红书两套完整素材。
> 输出成品结构见 `../assets/templates/material-package.md`，本文件是产出规范与写法准则。

## 一、执行流程

1. **识图 / 读资料**：提取产品形态、材质、颜色、规格、核心功能、使用场景、目标人群、价格带、竞品差异点。
2. **卖点分层**：把识别到的信息压缩成「1 个主卖点 + 2~3 个支撑卖点 + 1 个信任背书」。主卖点必须是用户可感知的结果，不是参数。
3. **痛点映射**：为每个卖点配一个具体痛点场景（谁、在什么场景、遇到什么麻烦）。痛点要具体到画面能拍出来。
4. **双平台改写**：同一条卖点，抖音写成「强钩子 + 强利益 + 强指令」，小红书写成「真实体验 + 场景化分享 + 弱引导」。
5. **合规过滤**：过一遍 `compliance-guardrails.md`，替换所有极限词与功效宣称。
6. **自检打分**：调用子模块 3 打分，低于 60 分必须重写而非微调。

## 二、小红书素材包

### 1. 笔记标题（3 版备选）

三个方向各出一版，让用户做 A/B：

| 方向 | 公式 | 示例结构 |
|---|---|---|
| 痛点型 | 人群 + 痛点 + 转折 | 「租房党别踩坑，这个 XX 我用了 3 个月」 |
| 效果型 | 时间/数量 + 结果 | 「坚持用了 2 周，XX 真的不一样了」 |
| 测评型 | 身份背书 + 横评 | 「买了 5 款 XX 实测，只推荐这一个」 |

标题要求：≤ 20 字；埋 1 个核心品类词；不用感叹号堆砌；不出现绝对化用语。

### 2. 正文种草文案（2 版）

**版本 A｜温柔真实种草版**（适合日常分享调性、女性向类目）

结构：`场景切入（1 句）→ 我的困扰（1~2 句）→ 怎么发现这个产品（1 句）→ 真实使用感受（分点 2~3 条）→ 适合谁 / 不适合谁（1 句）→ 软引导（1 句）`

语气要点：第一人称、口语化、允许出现「不是完美的」这类真实感表述；不写「亲测有效」「立刻见效」。

**版本 B｜干货测评版**（适合 3C、家电、日用、母婴等决策理性类目）

结构：`结论前置 → 选择标准（3 条）→ 横向对比维度 → 为什么选它（对应标准逐条）→ 使用场景清单 → 避坑提醒`

语气要点：给判断依据而非结论口号；用可验证的参数、材质、尺寸、使用次数替代形容词。

两版都需嵌入 3~5 个搜索词（自然融入句子，不堆砌），埋词方案见子模块 6。

### 3. 图文笔记图片排布方案

| 图位 | 内容 | 作用 |
|---|---|---|
| 第 1 图 | 封面：产品 + 一句核心利益点大字 | 决定点击率 |
| 第 2 图 | 使用场景实拍（人物出镜） | 建立代入感 |
| 第 3 图 | 产品细节特写 | 建立质感信任 |
| 第 4 图 | 对比图（使用前/使用后，或与替代方案对比） | 制造说服力 |
| 第 5 图 | 规格参数 / 成分 / 材质表 | 消除决策疑虑 |
| 第 6 图 | 使用步骤或搭配建议 | 提升使用想象 |
| 第 7 图 | 包装开箱 / 全家福 | 补充真实感 |
| 第 8 图 | 常见问题答疑 | 拦截评论区疑问 |
| 第 9 图 | 购买信息 / 引导语（弱） | 转化 |

图片数量按类目裁剪，3C/家电保留参数图与对比图，美妆/服饰可压缩到 6 图。

### 4. 封面 AI 生图提示词

小红书封面提示词模板（中文可直接用于生图工具）：

```
主体：{产品}，{颜色/材质}，居中偏左构图
场景：{真实生活场景，如木质书桌/浴室台面/客厅沙发}
光线：自然光，柔和侧光，无强阴影
色调：低饱和暖调，奶油色系
风格：小红书原生实拍感，手机拍摄视角，微颗粒质感
构图：竖版 3:4，上方留白用于加文字
禁止：纯白背景、影棚打光、夸张特效、文字水印
```

### 5. 笔记埋词方案 + 话题标签

- 埋词位置优先级：标题 > 首段前两句 > 正文小标题 > 结尾。
- 每个笔记布 1 个核心品类词 + 2 个长尾词 + 1 个场景词。
- 话题标签：1 个品类大词 + 2 个场景标签 + 2 个长尾标签 + 1 个品牌词，共 5~6 个，不堆到 10 个。

## 三、抖音素材包

### 1. 短视频脚本（完整分镜）

必须逐行给出，字段固定：

| 时间 | 画面 | 运镜/景别 | 口播字幕 | 音效/BGM | 备注 |
|---|---|---|---|---|---|

时长结构（建议 21~35 秒）：

- **0~3 秒 钩子**：痛点直击 / 反常识结论 / 强利益点。三选一，不做铺垫。
- **3~8 秒 问题放大**：把痛点的后果说具体，制造情绪。
- **8~18 秒 产品解法**：展示使用过程，卖点只讲 1 个主卖点 + 1 个支撑点。
- **18~25 秒 信任背书**：销量、复购、材质、检测报告、真实反馈（不得编造）。
- **25~30 秒 转化引导**：明确指令 + 稀缺理由（活动时间、赠品、规格），引导点购物车。

硬性要求：3 秒内出现产品；口播语速 ≥ 5 字/秒；每 3~5 秒一个画面切换；前 3 秒不出现品牌 logo 特写。

### 2. 短视频封面提示词

```
主体：{产品}占画面 1/2，{动作或使用瞬间}
背景：{高对比纯色或虚化场景}
文字：预留上方 1/3 空间（后期加 6~8 字痛点大字）
光线：硬光，产品高光清晰
风格：抖音信息流高点击风格，主体突出、色彩饱和
构图：竖版 9:16
禁止：堆叠多个元素、模糊主体、复杂背景
```

### 3. 直播单品口播话术（短视频引流直播间可用）

结构：`留人（1 句）→ 痛点共鸣（2 句）→ 产品出场 + 主卖点（3 句）→ 现场演示动作（1 个）→ 价格锚点（原价/现价/赠品）→ 逼单（限量/限时）→ 循环`

话术要写成可直接念的短句，每句 ≤ 15 字。演示动作必须能在镜头前 10 秒内完成。

### 4. 抖音标题 + 评论区置顶 + 话题标签

- **视频标题**：≤ 25 字，包含 1 个搜索词 + 1 个利益点，可用数字与对比。
- **评论区置顶**：补充规格/活动/发货信息 + 引导点击购物车，不重复标题。
- **话题标签**：1 个品类大词 + 1 个场景词 + 1 个产品词 + 1 个品牌词，共 4~5 个。

## 四、跨平台改写对照

| 维度 | 抖音 | 小红书 |
|---|---|---|
| 语气 | 强指令、短句、节奏快 | 分享口吻、长句、有停顿 |
| 卖点呈现 | 短平快，1 个主卖点打透 | 场景化，卖点藏在体验里 |
| 引导 | 明确行动指令、逼单 | 弱引导，评论区/主页承接 |
| 信任 | 数据、销量、直播背书 | 真实使用痕迹、细节图、不完美感 |
| 禁忌 | 前 3 秒无钩子、语速慢 | 硬广腔、通篇参数、强叫卖 |

## 五、输出前自检清单

- [ ] 每条卖点都能对应到画面，不存在「说出来但拍不出来」的卖点
- [ ] 前 3 秒钩子已明确写出，且不含产品名
- [ ] 全文无极限词、无功效承诺（对照 `compliance-guardrails.md`）
- [ ] 小红书版本没有硬广腔，抖音版本没有拖沓铺垫
- [ ] 埋词自然，未出现关键词堆砌
- [ ] 已标注「预估，以账户实际大盘数据为准」
