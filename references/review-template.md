# 子模块 4：投放复盘模板（标准化｜全类目，短视频 + 直播）

> 触发：用户提供投放周期数据，需要标准化复盘输出。
> 成品交付见 `../assets/templates/review-report.md`；本文件是填写规范与判断逻辑。

## 一、复盘基础信息

| 字段 | 说明 |
|---|---|
| 投放周期 | 起止日期，跨大促需标注 |
| 平台 | 千川 / 小红书乘风 / 双平台 |
| 产品类目 | 美妆 / 家居 / 食品 / 3C / 服饰 / 日用 / 其他 |
| 客单价 | 元 |
| 毛利率 | % |
| 保本 ROI | 1 ÷ 毛利率，保留两位小数 |
| 总预算 | 元（分平台列示） |
| 投放目标 | 短视频带货 / 直播带货 / 笔记种草 / 商品卡 |

## 二、核心数据汇总

### 通用指标

总消耗、成交金额、ROI、CTR、CPC、CPM、CVR、加购成本、千次成交成本。

### 直播额外指标

直播间进入率、平均停留时长、商品点击率、互动率（评论/点赞/加粉）。

### 千川 vs 乘风 关注口径差异

- 千川短视频：看 **3 日 ROI**
- 千川直播：看直播间停留、商品点击、成交 ROI
- 小红书乘风：看 **7 日支付 ROI**

复盘时必须声明用的是哪个口径，禁止混用。

## 三、分计划拆解

把计划分成三类分别列出，每条计划给出：计划名、消耗、成交、ROI、CTR、CVR、结论。

- **优质计划**：ROI ≥ 保本线且消耗稳定 → 保留 + 可加预算
- **低效计划**：ROI < 保本线但 > 0.6×保本线 → 优化素材/定向后再观察
- **空耗计划**：消耗 > 200 元且 0 成交，或 ROI < 0.6×保本线 → 关停

## 四、亮点总结

必须落到可复制的动作上，禁止写「素材不错」这类空话：

- 跑量素材：哪条素材、消耗占比、它的共性特征是什么
- 有效人群：哪个定向包/人群标签贡献了主要成交
- 高转化关键词：哪些搜索词带来成交，匹配方式是什么
- 有效策略：出价区间、时段、素材形式（口播/剧情/测评）中哪个起作用

## 五、问题诊断（按出现频率排查）

| 症状 | 常见根因 |
|---|---|
| 消耗不足 | 出价低于大盘、素材未过冷启动、定向过窄、预算受限 |
| 转化下滑 | 落地页/详情页改动、评价变差、素材疲劳、竞品降价 |
| 人群跑偏 | 定向过宽或过窄、系统探索偏离、素材调性与人群不符 |
| 素材疲劳 | 素材超生命周期（7~14 天）、同一素材重复投放 |
| 出价不合理 | 单次调价幅度过大、频繁改价打断模型学习 |
| 直播专项 | 直播间画面/灯光问题、主播话术留不住人、库存或价格挂错 |

## 六、归因分析

按以下顺序排查，先排除外部再归因内部：

1. 大盘波动（类目流量、竞品动作、平台活动）
2. 素材衰退（CTR 环比下降 > 15% 即为衰退信号）
3. 落地页 / 商品详情页
4. 评价与口碑（差评新增、评分下降）
5. 出价与预算调整记录
6. 定向调整记录

## 七、后续优化动作

必须写成可执行的清单，含具体数值：

- 启停：关停 X 条计划（列名），新开 X 条
- 调价：单次幅度 ≤ 0.05~0.1 ROI，写明从多少调到多少
- 预算转移：从哪个计划转到哪个，金额
- 素材上新：上新数量、方向、上线时间
- 关键词：新增 X 个、暂停 X 个、匹配方式调整
- 定向：新增/剔除人群包，说明理由
- 直播：调整直播时段、主播话术要点、直播间场景改动

## 八、下阶段目标

- 目标 ROI（须 ≥ 保本 ROI）
- 预算分配（平台间比例）
- 素材上新数量与测试条数
- 测试方向（新人群 / 新素材形式 / 新关键词）

## 九、风险预警

- 素材生命周期剩余天数
- 平台审核风险（是否有违规词、素材是否被驳回）
- 大促流量波动（竞价上涨、保本 ROI 需上浮的幅度）

## 十、输出纪律

- 所有结论必须挂靠数据，不写无数据支撑的判断。
- 优化动作必须带数值与时间，不写「适当调整」。
- 结尾统一标注：「以上为基于历史数据的复盘与预估，以账户实际大盘数据为准。」
