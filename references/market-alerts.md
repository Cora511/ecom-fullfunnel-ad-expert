# 子模块 5：大盘预警子模块（千川 + 乘风双平台｜短视频 & 直播）

> 触发：需要监控投放风险、给预警结论，或用户问「账户会不会出问题」。
> 输出必须是：风险等级（低/中/高）+ 根因 + 紧急操作动作 + 观察周期。

## 一、流量波动预警

### 千川（短视频 + 直播）

| 监控指标 | 预警红线 | 风险等级 |
|---|---|---|
| 消耗 | 连续 2 天下滑 > 30% | 中 |
| ROI | 连续 2 天下跌 > 20% | 高 |
| CPM | 突变 ±30% | 中 |
| CTR | 环比下降 > 15% | 中（素材衰退信号） |
| 直播间进人量 | 环比暴跌 > 40% | 高 |
| 直播间平均停留 | 大幅下降（低于历史均值 30%） | 中 |

### 小红书乘风（笔记 + 直播投放）

| 监控指标 | 预警红线 | 风险等级 |
|---|---|---|
| 笔记曝光 | 连续 2 天暴跌 > 30% | 中 |
| 7 日 ROI | 持续下滑（连续 3 天下跌） | 高 |
| 搜索词热度 | 核心词热度大幅下降 | 中 |
| 直播投放观看人数 | 环比下滑 > 30% | 中 |

## 二、账户健康预警

### 千川

- 低效空耗计划堆积（空耗计划数 > 总计划数 30%）
- 频繁审核驳回（单周驳回 > 3 条）
- 账户消耗受限（触发风控或余额不足）
- **禁止**一次性批量新建大量计划（建议单次 ≤ 5 条）

### 小红书乘风

- 素材被判定硬广
- 笔记违规限流
- 商品卡关联异常
- 直播素材违规预警

## 三、大促 & 季节预警

- 时间节点：618、双 11、双 12、年货节、开学季、换季
- 预警内容：
  - 竞价上涨幅度预估（大促期 CPM 通常上浮 20%~50%）
  - 保本 ROI 需上浮（成本上涨时按同比例上浮，或直接暂停低效计划）
  - 建议提前 X 天完成素材储备与计划搭建，避开大促当天临时调价
- 类目季节性波动：服饰换季、食品节令、美妆换季、3C 新品周期

## 四、素材生命周期预警

- 短视频素材常规生命周期 **7~14 天**
- 预警动作：
  - 素材上线第 7 天起提示储备新素材
  - 素材上线第 10 天起提示「即将断流，需上新 N 条」
  - 素材 CTR 环比下降 > 15% 时立即提示替换

```

预警时间：YYYY-MM-DD
监控范围：{平台 / 账户 / 计划组}

| 序号 | 预警项 | 当前值 | 红线值 | 风险等级 | 根因 | 紧急动作 | 观察周期 |
|---|---|---|---|---|---|---|---|
| 1 | | | | 高/中/低 | | | |

### 高优先级动作（今日必须执行）
1. ……

### 中优先级动作（24~48 小时内执行）
1. ……

### 持续观察项
- 观察指标：…… 观察周期：…… 触发下一步动作的条件：……
```

## 六、风险等级判定原则

- **高**：已直接影响成交或可能导致账户受限，需当日处理
- **中**：趋势性恶化，48 小时内处理可挽回
- **低**：需要留意但不影响当前投放，纳入观察

## 七、纪律

- 不夸大风险制造焦虑，也不隐瞒风险。
- 每个预警必须给出可执行动作，不给「建议关注」这类无效建议。
- 明确标注「预警为基于历史阈值的经验判断，实际以平台大盘与账户数据为准」。
