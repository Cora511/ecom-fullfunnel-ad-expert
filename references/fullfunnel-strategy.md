# 全域闭环策略与预算拆分

## 一、三阶段闭环

### 阶段 1｜小红书乘风种草蓄水（占总预算 30%~40%）

- 产出原生种草笔记，布局关键词埋词
- 乘风笔记加热 + 搜索广告，积累品类词/品牌词搜索资产
- 沉淀意向人群（收藏、评论、进店、关注）
- 小红书直播种草蓄水

### 阶段 2｜千川短视频 + 直播收割（占总预算 60%~70%）

- 短视频挂车 + 直播间投流
- 通投 + 搜索千川，承接小红书种草回流搜索流量、商城搜索人群
- 商品卡免费流量联动付费放大

### 阶段 3｜人群回流闭环

- 千川成交人群包反向推送小红书，二次种草复购
- 双向放大搜索词权重：小红书把跑出互动的词反馈到千川搜索计划，千川把高转化搜索词反哺小红书埋词

## 二、预算拆分方法

### 基础比例

| 平台 | 占比 | 说明 |
|---|---|---|
| 小红书乘风 | 30%~40% | 蓄水端，7 日 ROI 口径 |
| 巨量千川 | 60%~70% | 收割端，3 日 ROI 口径 |

### 按类目决策周期调整

| 类目特征 | 调整方向 |
|---|---|
| 决策周期长、客单价高（家电、3C、家具、母婴大件） | 乘风占比上调至 45%~50%，给足种草周期 |
| 决策快、冲动型、低客单（日用、食品、美妆小样、服饰基础款） | 千川占比上调至 70%~75% |
| 强内容驱动、视觉属性强（美妆、服饰、家居） | 乘风占比 40% 左右，重素材质量 |
| 强功效、需教育（保健、功能性护肤） | 乘风占比上调，用内容做教育 |

### 按投放阶段调整

| 阶段 | 分配 |
|---|---|
| 新品冷启动（0~14 天） | 乘风 50%，千川 50%，千川侧先用短视频测素材 |
| 日常稳投（15~60 天） | 乘风 35%，千川 65% |
| 大促放量 | 乘风 30%，千川 70%，提前 3~5 天完成搭建 |

### 拆分计算示例

总日预算 10,000 元、日常稳投阶段：

- 小红书乘风：3,500 元（笔记加热 2,000 + 搜索广告 1,500）
- 巨量千川：6,500 元（短视频 3,000 + 直播 2,500 + 搜索 1,000）

具体拆分需按类目、客单价、保本 ROI 重新测算，可用 `../scripts/roi_calc.py`。

## 三、跨平台素材改造

同一套产品素材，按平台改写：

| 元素 | 小红书版 | 抖音版 |
|---|---|---|
| 封面 | 生活场景实拍 + 小字利益点 | 产品大图 + 大字痛点 |
| 开头 | 场景描述 | 3 秒钩子 |
| 卖点 | 藏在体验里 | 直给 + 画面佐证 |
| 引导 | 弱引导、评论区承接 | 强指令、点购物车 |
| 时长 | 图文为主 | 21~35 秒短视频 |

## 四、核心指标公式

| 指标 | 公式 |
|---|---|
| 保本 ROI | 1 ÷ 毛利率 |
| 目标 ROI | 保本 ROI × (1 + 目标利润率) |
| ROI | 成交金额 ÷ 消耗 |
| CTR | 点击量 ÷ 曝光量 |
| CVR | 成交订单数 ÷ 点击量 |
| CPC | 消耗 ÷ 点击量 |
| CPM | 消耗 ÷ 曝光量 × 1000 |
| 加购成本 | 消耗 ÷ 加购数 |
| 千次成交成本 | 消耗 ÷ 成交订单数 × 1000 |
| 可承受 CPC | 客单价 × CVR ÷ 目标 ROI |

## 五、人群回流操作步骤

1. 在千川后台导出成交人群包（按近 30 天成交/加购/进店分层）
2. 将人群包推送到小红书，作为乘风投放的定向人群
3. 用「复购/二次种草」内容承接，避免直接硬推同款
4. 观察回流人群的 7 日 ROI 与自然搜索量变化
5. 把跑出高互动的搜索词反馈回千川搜索计划

## 六、大促投放方案框架

| 时间 | 动作 |
|---|---|
| 大促前 10~14 天 | 乘风蓄水：加大笔记投放，积累搜索资产与人群 |
| 大促前 3~5 天 | 千川搭建计划、储备素材、完成 A/B 测试 |
| 大促前 1~2 天 | 提价抢量，保本 ROI 基准上浮 |
| 大促当天 | 重点守 ROI，暂停低效计划，集中预算打优质计划 |
| 大促后 3~7 天 | 承接长尾流量，人群回流二次种草 |

## 七、输出纪律

- 预算比例是起点不是结论，必须结合用户类目与客单价调整。
- 所有 ROI 目标必须 ≥ 保本 ROI，且标注为预估。
- 结尾统一声明：「预估，以账户实际大盘数据为准，不承诺必爆、不承诺稳定 ROI。」
