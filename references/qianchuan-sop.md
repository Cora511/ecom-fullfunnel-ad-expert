# 巨量千川投放 SOP（短视频 + 直播）

## 一、可用的推广类型

| 类型 | 适用场景 | 优化目标 |
|---|---|---|
| 短视频带货（极速推广） | 新品冷启动、快速测素材 | 成交 / 下单 |
| 短视频带货（专业推广） | 稳定期精细化运营 | 成交 / ROI |
| 直播间投流 | 直播引流、直播间成交 | 直播间成交 / 进入直播间 |
| 搜索千川 | 承接种草回流搜索流量 | 成交 / ROI |
| 商品卡 | 承接商城免费流量并付费放大 | 成交 / ROI |

## 二、账户结构搭建规范

### 结构层级

```
账户
└── 计划（按目标/素材类型分组）
    └── 广告组（按人群定向分组）
        └── 素材（A/B 测试对照）
```

### 搭建数量纪律

- **禁止一次性批量新建几十条计划**。单次新建 ≤ 5 条，观察 1~2 天再决定是否继续新建。
- 冷启动期建议同时在线计划数 5~10 条，超过后单条计划拿量会明显下降。
- 一条计划内挂 2~4 条素材做 A/B，不要一条计划只挂 1 条。

### 分阶段搭建

| 阶段 | 目标 | 计划结构 | 出价策略 |
|---|---|---|---|
| 冷启动（0~3 天） | 跑出转化样本 | 5~8 条计划，广泛定向，多素材 | 略高于系统建议出价 5%~10% |
| 稳定期（4~14 天） | 稳定消耗与 ROI | 保留优质计划，关停空耗 | 逐步下调至保本 ROI 对应的出价 |
| 放量期（15 天+） | 扩大规模 | 复制优质计划，横向拓展定向 | 小幅提价，单次 ≤ 0.05~0.1 ROI |
| 大促期 | 抢量守 ROI | 提前 3~5 天搭建，提前储备素材 | 出价上浮，同时上浮保本 ROI 基准 |

## 三、冷启动规则（硬约束）

- 必须给到 **20~50 个转化样本**的观察期，期间不因短期 ROI 波动关停计划。
- 观察期内不改出价、不改定向、不频繁启停。
- 冷启动失败的判断：消耗达到目标出价的 3~5 倍仍无转化 → 关停并换素材。
- 不要频繁大幅度修改计划，模型学习会被打断。

## 四、定向策略

| 定向类型 | 用法 |
|---|---|
| 系统智能推荐 | 冷启动期主力，让模型自己找人 |
| 自定义人群（DMP） | 稳定期叠加，用店铺人群、成交人群做种子扩量 |
| 达人相似粉丝 | 类目达人定向，适合种草回流人群承接 |
| 行为兴趣 | 稳定期精细化，注意不要叠加过多条件导致跑不出去 |
| 搜索定向 | 搜索计划使用，配合关键词 |

原则：冷启动从宽，稳定期收窄，放量期再放开。定向叠加层级不超过 3 层。

## 五、出价与 ROI 目标

- 出价基准：以「保本 ROI」倒推可承受 CPC，再对比系统建议出价。
- 短视频看 **3 日 ROI**，直播看直播间停留 + 商品点击 + 成交 ROI。
- 单次调价幅度 ≤ 0.05~0.1 ROI，调价后观察至少 2 小时再决定下一步。
- ROI 低于保本线时**不追加预算**。

## 六、短视频投流要点

- 前 3 秒必须有钩子，3 秒内出现产品。
- 时长建议 21~35 秒，每 3~5 秒切换画面。
- 素材上线后第 7 天开始储备新素材（生命周期 7~14 天）。
- 同一素材不要在多条计划重复投放，会造成内部竞争。

## 七、直播投流要点

- 关注指标：直播间进入率、平均停留、商品点击率、成交 ROI。
- 直播间画面合规：无违规话术、无绝对化用语、商品与讲解一致。
- 投流与直播节奏配合：开播前 15 分钟起投，用于暖场与拉初始流量。
- 主播话术要能与投放素材承接一致，避免「素材说 A、主播讲 B」。

## 八、7 天调优规则（可直接照做）

| 时间 | 动作 |
|---|---|
| 第 1 天 | 搭建 5~8 条计划，广泛定向，多素材，出价略高于建议价 |
| 第 2 天 | 只看消耗与是否有转化，不调价；关停零消耗计划 |
| 第 3 天 | 关停无转化计划；对有点击无转化的计划换素材，不动出价 |
| 第 4 天 | 保留优质计划，对 ROI 达标计划加预算 20% |
| 第 5 天 | 复制 1~2 条优质计划换定向扩量；淘汰 CTR 垫底素材 |
| 第 6 天 | 优化出价：ROI 超保本线 30% 以上可小幅提价放量 |
| 第 7 天 | 出复盘：优质/低效/空耗计划分类，制定下周素材上新计划 |

## 九、常见问题速查

| 问题 | 处理动作 |
|---|---|
| 计划没消耗 | 检查出价是否过低、定向是否过窄、素材是否审核通过、预算是否受限 |
| 有消耗无转化 | 换素材（首因），其次检查落地页与价格 |
| ROI 突然掉 | 先查大盘与竞品动作，再查素材衰退、评价变化、出价调整记录 |
| 计划掉量 | 不要立刻提价，先看是否素材疲劳，优先上新素材 |
| 审核被驳回 | 检查违禁词（对照 `compliance-guardrails.md`），改后重新提交 |

## 十、输出纪律

所有给出的数值（出价、预算、ROI 目标）必须标注为预估，并说明「以账户实际大盘数据为准，不承诺必爆、不承诺稳定 ROI」。
