# 子模块 2：爆款素材拆解复刻模块

> 触发：用户输入抖音/小红书爆款视频或图文链接，要求拆解并复刻同款带货素材。

## 一、输入处理规则（重要）

优先尝试获取链接内容。若无法访问（需登录、动态渲染、无权限），**必须**向用户索取以下任一材料，禁止凭标题或封面臆造：

- 视频完整逐字稿 / 字幕文本
- 分镜截图（按时间顺序，至少 6 张）
- 图文笔记的正文全文 + 图片顺序描述
- 关键数据（点赞、评论、收藏、发布时间）

拿到材料后，先声明「以下拆解基于用户提供的材料，未提供的部分标注为待补充」。

## 二、第一步：爆款诊断

按 8 个维度逐项输出，每项必须给结论 + 依据：

| 维度 | 要判断什么 |
|---|---|
| 爆款类型 | 痛点型 / 测评型 / 场景种草 / 剧情带货 / 对比实验 / 教程干货 |
| 钩子类型 | 提问式 / 反常识 / 结果前置 / 冲突开场 / 身份代入 |
| 完播逻辑 | 靠什么留住人：悬念、节奏切换、信息密度、情绪推进 |
| 卖点排布节奏 | 第几秒出现产品、主卖点在第几秒、共讲几个卖点 |
| 画面分镜 | 景别变化频率、有无人物出镜、拍摄视角 |
| 口播节奏 | 语速、句长、停顿位置、是否有口头禅式记忆点 |
| 封面逻辑 | 封面大字文案、构图、颜色对比、信息层级 |
| 人群与转化引导 | 内容对谁说、引导动作是什么（购物车/评论/主页/私信） |
| 适配平台 | 判断更适合千川投流还是小红书乘风加热，并给理由 |

## 三、第二步：结构模板提取

把爆款还原成可复用的「骨架」，而不是内容本身。输出格式：

```
【钩子公式】{一句话抽象公式}
【痛点-卖点对应表】痛点 → 卖点 → 证据形式
【分镜骨架】段落 → 时长占比 → 画面类型 → 信息目的
【口播节奏骨架】句长 / 语速 / 停顿规律
【转化引导骨架】引导位置 + 引导话术类型
【封面骨架】构图 + 文字位置 + 字号层级
```

同时明确标注：**哪些是结构（可复用），哪些是原创表达（不可复用）**。

## 四、第三步：二创改写规则（合规硬约束）

复刻 = 复用结构 + 完全重写表达。以下行为禁止：

- 直接搬运原视频口播文案、字幕文本
- 使用原视频画面素材、截图、BGM 原声（版权风险）
- 照抄原文标题与话题标签组合
- 复刻达人个人形象、口癖、独特记忆点

必须做的：

- 口播文案 100% 重写，仅保留句式节奏
- 画面重新拍摄，仅参考分镜逻辑与景别节奏
- 卖点换成用户自家产品的真实卖点与证据
- 标题与标签重新组合，替换为自家品类词与品牌词

## 五、第四步：产出全套复刻素材

按 `material-creation.md` 的产出规范输出，内容替换为用户自家产品：

1. 笔记/视频标题（3 版）
2. 图文笔记正文（2 版）
3. 短视频分镜脚本（完整表格）
4. 直播单品口播话术
5. 封面提示词（抖音 + 小红书各一版）
6. 话题标签组合
7. 埋词方案

输出时在开头保留「爆款结构对照表」，让用户看到每一段对应原爆款的哪个位置。

## 六、第五步：投流适配建议

给出明确结论 + 理由 + 测试方案：

| 判断 | 依据 |
|---|---|
| 适合千川短视频投流 | 3 秒钩子强、卖点直给、有明确转化指令、时长 ≤ 30 秒 |
| 适合小红书乘风笔记加热 | 氛围感强、种草口吻、决策链路长、无强叫卖 |
| 双平台可改 | 结构通用，需按 `material-creation.md` 的跨平台对照表改写 |

测试建议必须包含：测试素材条数、单条测试预算、观察指标、判断周期、淘汰标准。

## 七、输出模板

```
## 一、爆款诊断
（8 维度表格）

## 二、底层结构模板
（骨架提取，标注可复用/不可复用）

## 三、二创全套素材
（标题 / 正文 / 分镜 / 口播 / 封面 / 话题 / 埋词）

## 四、投流适配与测试建议
（适配平台判定 + 测试方案）

## 五、版权与合规声明
本方案仅复用爆款结构框架，全部文案与画面均为重新创作，
未搬运原素材内容。所有预估数据以账户实际大盘为准。
```
